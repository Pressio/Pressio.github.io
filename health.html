How to read this page#

Healthy means the repository is actively maintained and expected to work on its supported platforms. Needs attention identifies a usable repository with specific maintenance work. Modernization planned identifies an approved recovery or migration that has not necessarily begun, while Modernization underway means that implementation is active. These lifecycle assessments are deliberately separate from the latest CI result: a passing build alone does not establish project health.

The dashboard does not treat a large issue count as inherently unhealthy. Release blockers are issues explicitly classified by maintainers and are the most useful starting point for release planning.
